# GitHub Issue Engagement

When a request involves retrieving GitHub issues, reading issue discussions,
adding reactions, or posting issue replies, load and follow the
`github-issue-engagement` skill at:

`.\.agents\skills\github-issue-engagement\SKILL.md`

Use the skill's workflow and safeguards rather than duplicating them here.

## Subagents

For parallel or delegated execution of engagement tasks across issues or repositories, use the `github-issue-agent` subagent defined at:

`.\.agents\agents\github-issue-agent.md`
